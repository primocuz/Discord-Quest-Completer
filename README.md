# Tomst-Quest

Discord quest automation script.

## Requirements

- Discord **desktop app** (the web version will not work)
- [Vencord](https://vencord.dev) installed on your Discord desktop app

## How to use

1. **Download the Discord desktop app** from the official Discord website. Do not use the web version.
2. **Download and install Vencord.** Search for "Vencord" on Google and use the official site.
3. **Restart Discord** after installing Vencord, then open it.
4. Press **Ctrl + Shift + I** to open Developer Tools.
5. Go to the **Console** tab.
6. Open `Tomst.js` from this repository, **copy the whole file**, and **paste it** into the console.
7. Press **Enter**. The script will start running and you can use it.

Thanks for using Tomst-Quest!
